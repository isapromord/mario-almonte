# Mario Almonte — Bienes Raíces • Liderazgo • Crecimiento

Landing page ejecutiva de alto impacto para **Mario Almonte** (CEO & Broker Owner de Alveare Realty), desarrollada bajo estándares cinemáticos de diseño internacional (Awwwards / Swiss Editorial).

---

## 🚀 Despliegue en Vercel

Este proyecto está pre-configurado para desplegarse instantáneamente en **Vercel**:

```bash
# 1. Despliegue directo mediante Vercel CLI:
vercel

# 2. O conecta este repositorio en https://vercel.com
# Framework Preset: Other / Static Site
# Root Directory: ./
# Output Directory: ./
```

El archivo `vercel.json` gestiona automáticamente el enrutamiento limpio y la redirección a la **Versión 2** (versión elegida en producción).

## 🛠️ Stack Tecnológico

- **HTML5 Semántico:** Arquitectura accesible y estructurada para SEO y GEO (AI Search).
- **CSS3 Moderno:** Variables nativas, Glassmorphism, Flexbox, CSS Grid y media queries para móvil.
- **GSAP 3 + ScrollTrigger:** Secuencias de scroll suave, carrusel horizontal con *matchMedia* y lectura línea por línea.
- **Lenis Smooth Scroll:** Desplazamiento fluido a 60fps con inercia cinemática.
- **Lucide Icons:** Iconografía vectorial minimalista.

---

## 📱 Optimización Mobile

- **Hero Unobstructed:** El retrato de Mario cuenta con un contenedor dedicado entre el titular y el texto, garantizando 100% de visibilidad sin que los textos tapen su rostro.
- **Navegación Horizontal Táctil:** Controles con flechas táctiles `[ < ]` y `[ > ]`, contador dinámico `01 / 04` y *touch-swipe con scroll-snap*.
